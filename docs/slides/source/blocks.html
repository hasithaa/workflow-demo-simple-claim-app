Three building blocks

1 · Start

A business event starts a process

Ann submits a claim. The API starts the workflow under the claim id, so anything about this claim finds its process later.

runWithId

2 · Wait

The process waits for an event

The workflow parks until the bill arrives, for seconds or weeks. It survives restarts; nothing polls.

Await Data · Send Data

3 · Ask

The process asks a person

A task for the MANAGER role. Any app can list it and complete it through the built-in Management API.

Human Task

Three building blocks cover this use case, and most approval processes. Start a process when something happens, under a business id. Wait for an event, durably. Ask a person, through a task any app can list and complete.
